# Data license and provenance

The datasets in this directory, and the per-example model outputs under
`results/`, are released under the
[Creative Commons Attribution-NonCommercial 4.0 International (CC BY-NC 4.0)](https://creativecommons.org/licenses/by-nc/4.0/)
license. Code is licensed separately (MIT, see the repository `LICENSE`).

## Why CC BY-NC 4.0

| Dataset | Derived from | Upstream license |
|---|---|---|
| `data/stage_l/` (CICM: controlled preference dialogues) | preference topics and value vocabulary from PrefEval (Zhao et al., 2025); dialogue template packs written by GPT-4.1 with every controlled value, position, and answer inserted by the generator program | PrefEval data: CC BY-NC 4.0 |
| `data/stage_g/external/` (BABILong, Entity Tracking, RULER-VT subsets) | public long-context and state-tracking benchmarks, re-serialized with the old-state labels used in the paper | see each benchmark's repository (BABILong, Kim & Schuster 2023 entity tracking, NVIDIA RULER) |
| `data/p0.jsonl`, `data/parallel.jsonl`, `data/hard_tier.jsonl`, `data/stage_a.jsonl`, `data/stage_c/`, `data/stage_d/`, `data/stage_e/` | fully synthetic, generated by scripts in `src/` from fixed seeds | none |

ICF-Bench items are not redistributed here; the ICF-Bench evaluation scripts
(`src/icf_*.py`) expect the benchmark's own release.
